# Desafio POO I - Cadastro de Participantes

Este projeto foi desenvolvido para praticar os conceitos de Programação Orientada a Objetos (POO) em Java.

A classe Participante possui os atributos nome, email e tipo de participação.

Os atributos são privados, seguindo o conceito de encapsulamento.

Foi criado um construtor para cadastrar os dados de cada participante.

Também foram utilizados métodos getters para acessar nome, email e tipo de participação.

No programa principal foram criados três objetos da classe Participante.

Os três participantes foram testados e seus dados foram exibidos no console.

O projeto foi desenvolvido em Java e está organizado no GitHub.
